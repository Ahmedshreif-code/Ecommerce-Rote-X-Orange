## 🔎 Overview

**Ecommerce — Route x Orange** is a minimal, front-end-only online store built as part of the **Route x Orange** program. It fetches live product data from the **Route Academy E-commerce API**, renders it on a home page, provides a product details page, lets users add products to their cart, and includes a dedicated cart page to review the selected items.

The project focuses on delivering a working core flow quickly, rather than a full-featured store.

---

## ⏱ Project Background

This project was built in **approximately 2 hours** using **AI-assisted development**. The goal was to demonstrate how quickly a working API-driven interface can be produced when combining AI tooling with solid front-end fundamentals, while practicing real-world API consumption.

## 🎯 Scope

To keep the delivery fast and focused, this version covers **only**:

1. **Home page** — product listing powered by the API
2. **Product details page** — detailed view of a single product
3. **Add product to cart** — core cart interaction
4. **Cart page** — review the products added to the cart

Features such as authentication and checkout are **out of scope** for this version.

---

## 🧰 Tech Stack

- **HTML5** — page structure
- **CSS3** — styling and layout
- **JavaScript (Vanilla)** — API requests and cart logic
- **Route Academy E-commerce API** — product data source
- **AI tooling** — accelerated code generation and iteration

---

## 🔌 API Integration

All product and cart-related data is provided by the **Route Academy E-commerce API**, made available through the Route x Orange program. The project does not include a custom backend, database, or server-side code.

> **Note:** Because data is fetched live, an active internet connection is required.

## 🚀 Getting Started

### Prerequisites

- A modern web browser (Chrome, Edge, Firefox, Safari)
- Internet connection
- *(Optional)* [VS Code](https://code.visualstudio.com/) with the **Live Server** extension

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/Ahmedshreif-code/Ecommerce-Rote-X-Orange.git

# 2. Navigate into the project
cd Ecommerce-Rote-X-Orange
```

### Run

Open `index.html` directly in your browser, or right-click it in VS Code and choose **Open with Live Server**.
